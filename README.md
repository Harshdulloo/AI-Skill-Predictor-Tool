# AI Skill Predictor Tool

A full-stack learning analytics application that predicts a student's skill level using machine learning and provides AI-powered personalized guidance.

Live Demo: [ai-skill-predictor.streamlit.app](https://ai-skill-predictor-5dnao3lc5yxgmppj9ep9eq.streamlit.app)  
Backend API: [ai-skill-predictor-tool-1.onrender.com](https://ai-skill-predictor-tool-1.onrender.com)

---

## What it does

The system takes a student's test performance metrics as input and classifies them as **Beginner**, **Intermediate**, or **Advanced** using a trained Logistic Regression model. Beyond prediction, it provides an AI-powered chat assistant and personalized improvement plans — making it a complete learning evaluation system, not just a classifier.

---

## Features

### Student
- Secure registration and login with hashed passwords
- AI-based skill level prediction (7 performance metrics)
- Personalized 4-week improvement plan generated by AI after each prediction
- AI Learning Assistant — chat with an AI that knows your actual scores and history
- Personal prediction history
- Skill progress visualization over time

### Admin
- Role-based admin access via environment variables
- Analytics dashboard with KPIs, charts, and leaderboard
- Skill distribution analysis (donut chart)
- Difficulty vs skill outcome breakdown
- Consistency score distribution by skill level
- Monthly prediction trend
- Student-specific performance deep dive
- CSV export for reporting

## ML Pipeline

- **Dataset:** 1000 rows, 7 features (`marks`, `accuracy`, `time_taken`, `attempts`, `difficulty_level`, `topic_coverage`, `consistency_score`)
- **Models trained:** Logistic Regression, Random Forest
- **Accuracy:** 100% on test split (stratified 75/25)
- **Saved artifacts:** `skill_model.pkl`, `scaler.pkl`, `difficulty_encoder.pkl`

## How to Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/Harshdulloo/AI-Skill-Predictor-Tool.git
cd AI-Skill-Predictor-Tool
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Set up environment variables
Create a `.env` file in the project root:
```
ADMIN_USERNAME=your_admin_username
ADMIN_PASSWORD=your_admin_password
GEMINI_API_KEY=your_gemini_api_key
```

### 4. Start the backend
```bash
python -m uvicorn main:app --reload
```

### 5. Start the frontend
```bash
export PATH=$PATH:~/Library/Python/3.9/bin
streamlit run app.py
```

The app will be available at `http://localhost:8501`
